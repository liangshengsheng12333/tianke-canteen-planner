# 产品背景与功能清单

## 产品背景

学生在真实食堂选餐时，需要同时考虑窗口供应、实际价格、个人饮食目标和当天已经吃过的内容。项目将这些信息放进微信小程序的本地选餐与记录流程，并以 C++ 核心实现三种可选的规划算法。

当前演示候选使用西院西一食堂菜单：12 个窗口、166 个菜品技术实体、137 条可售报价。菜单覆盖来自现场照片、转录与后续补录；所附 3 张照片只展示部分窗口，不代表全部菜单。菜品营养值中包含有来源的估算；缺失值仍是未知，不是零，也不是实测。

## 算法与工程

三算法处理同一个规划目标并共享候选合法性和评分口径，但搜索方式不同：贪心逐步形成代表餐次后比较有限组合；DP按餐次扩展累计状态；BnB使用界限剪枝。三算法机制和 C++/小程序本地架构见 `04-三算法与架构配图/`，性能数据和算法边界见 `05-性能与答辩/`。

工程图按已验收 v2a 表述：共享 C++17 核心分别由 Native 工具链和 WASM 工具链构建；WASM 在小程序本地执行，Native CLI 用于电脑侧验证；user/dev 是小程序打包差异，不是 C++ 编译产物。
