## 三、核心结论摘要（详见 `完整分析.md`）

1. **共享层一**：`E_m`（枚举叶子数）由每窗报价数 `n` 与 `K` 决定，`C_m = min(E_m, 256)`；**候选上限只限保留数，不限枚举时间/枚举内存**（递归在截断后继续计数，`observed` 实际是全树叶子数）。
2. **greedy**：`O(Σ C_m·W_m·K³ + Ξ·(M²K²+L))`，`Ξ≤min(∏W_m, 200000)`；`searchComplete` 恒 false，永不声明最优。
3. **dp**：限额下 `O(M·(S·C)²·Q + M·S·C·(MK+Ĉ) + S·C·L)`；无截断 `O((∏C)²·Q)`。`S=32` 只限阶段间保留数，**真实处理量 `Σ|L|·C` 当前实测 16640**（=256+32×256+32×256）。
4. **BnB**：最坏指数，节点数 ≤`3∏C` 或 `≤Nlim`；**`maxSearchNodes` 是搜索量上限，不是耗时上限**（每节点/每叶成本不同，叶内还做 planKey SHA-256 且不可中断）。
5. **可证明性**：只有「无候选截断 + 无状态/节点/时限截断」时，DP/BnB 才能声明候选集内最优；greedy 永远不能。当前 v4 菜单三算法全部截断、`searchComplete=false`，因此**三者均不得声明全局最优**。
