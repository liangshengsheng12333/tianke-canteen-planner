## 逐项复核

### T03c13 山东杂粮煎饼

1. 官方疾控中心条目 [煎饼 1202](https://nlc.chinanutri.cn/fq/foodinfo/1202.html) 当前列示每100g：水分6.8g、1498kJ、蛋白质7.6g、脂肪0.7g、碳水83.8g。候选干物质折算系数 `50 / (100 - 6.8) = 0.53648069`；折算后每100g熟饼皮约192.08 kcal、P4.08g、F0.38g、C44.96g。110g对应211.284 kcal、P4.485g、F0.413g、C49.453g。该折算算术成立，50%水分仍是工艺假设，不是现场测量。
2. 候选JSON只保留契约字段 `carbDg`，未发现 `carbsDg`。候选注释与来源说明明确排叉只是替代估算；“配方吸油率已验证相符”断言已去除。25g薄脆、6g底油及饼皮含水率均标成假设，没有冒称现场称重。薄脆内含油脂已计入排叉条目，另列底油6g，按其配方边界没有重复计油。
3. 按候选所列每100g和份量，独立合计为 **471.4241 kcal / P13.8600g / F16.3971g / C69.1528g**，按整 kcal、分克四舍五入为 **471 / 139 / 164 / 692**，候选当前值在“采用其列出的输入值”这一前提下算术正确。
4. 但候选把豆油来源写作条目1041及 `.../1041.html`。现场打开该官方链接，页面标题为“绿鳍马面豚[面包鱼，橡皮鱼]”，不是豆油。官方豆油页面实际为 [豆油条目1497](https://nlc.chinanutri.cn/fq/foodinfo/1497.html)，当前列示3696kJ/100g、脂肪99.9g/100g；候选却采用3761kJ/100g、899kcal/100g。按该可定位页面能量值替换6g豆油，整份为 **470.4860 kcal / P13.8600g / F16.3971g / C69.1528g**，即 **470 / 139 / 164 / 692**。须更正豆油页面与数值并更新能量。若团队确实采用《成分表》纸本版本中的899 kcal数值，应在候选提供可独立定位的书页证据，并修正当前错误链接。
5. 来源证据05把“排叉”标成“01-1-504类似工艺”，但没有书页影像、页码或官方可查询的具体条目页。当前复核无法从该证据文件本身独立核实这一代码和值；它可以保留为明确的估算替代，需补具体书页定位，或避免将作者摘录表述成已独立核实的官方条目。

### T03c14 手抓饼

1. 官方疾控中心预包装食品标签页确认为[云鹤手抓饼](https://nlc.chinanutri.cn/food/03KqaiXHSPan6AjjRCOjWg.html)，厂家新乡云鹤食品有限公司、净含量400g、识别码6921406808370；每100g能量1360kJ、P6.6g、F14.1g、C42.7g。候选把它说明为代表性替代而非食堂实采品牌，边界正确。页面钠为**446mg/100g**，而候选和凭证摘录误写为508mg；此处只影响钠，不属于本轮四项目标值，但应修正来源摘录。
2. 候选使用90g饼皮、50g鸡蛋、45g土豆、3g豆油。对照其引用的官方食物成分查询页面：
   - [鸡蛋条目978](https://nlc.chinanutri.cn/fq/foodinfo/978.html)：页面为599kJ、P13.3g、F8.8g、C2.8g/100g；候选取615kJ、P12.6g、F9.0g、C1.5g。
   - [马铃薯条目313](https://nlc.chinanutri.cn/fq/foodinfo/313.html)：页面为328kJ、P2.0g、F0.2g、C17.2g/100g；候选取322kJ、P2.0g、F0.2g、C16.5g。
   - [豆油条目1497](https://nlc.chinanutri.cn/fq/foodinfo/1497.html)：页面为3696kJ、F99.9g/100g；候选取3761kJ、899kcal、F99.9g。三项候选数据可能来自其所称纸本表格，但当前没有页码/页证来解释差异；在线直链不能支撑候选填写值。
3. 严格按候选自身所列的组分值和份量，复算为 **427.66 kcal / P13.14g / F20.277g / C46.605g**，取整为候选 **428 / 131 / 203 / 466**。因此候选内部算术成立，但来源闭环未成立。
4. 若改按以上可定位页面的数据（云鹤标签1360kJ、P6.6/F14.1/C42.7；鸡蛋599kJ、P13.3/F8.8/C2.8；马铃薯328kJ、P2.0/F0.2/C17.2；豆油3696kJ、F99.9），四项重算为 **425.9034 kcal / P13.490g / F20.177g / C47.570g**，即 **426 / 135 / 202 / 476**。这一结果只是在所附可定位线上来源下的复算；若确有对应版本纸本原始数据，应以页证重核后确定最终值。
5. `carbsDg` 已删除。90g饼坯、鸡蛋50g、土豆45g、外加油3g均为典型份量假设。其“土豆丝大锅吸油1.5g”等精确工艺拆分没有现场证据，宜继续保留为假设，不作为实测事实。

### T03c15 海南鸡饭

1. 官方疾控中心[蒸米饭条目287](https://nlc.chinanutri.cn/fq/foodinfo/287.html)列493kJ、P2.6g、F0.3g、C25.9g/100g。按 `493 / 4.184 = 117.8298 kcal/100g`，197g为 **232.1248 kcal / P5.122g / F0.591g / C51.023g**。以197g米饭加3g油形成200g米饭基底是清晰的假设，不是食堂称重证据；本次没有再用旧116kcal值。
2. 鸡油证据 JSON 声称《成分表》第六版第一册第十章“精炼禽脂”897kcal、3755kJ、F99.7g/100g，但没有具体食物条目名/编码/页码或原表影像。它属于作者编写的证据摘录，不足以独立定位原表。证据文件另列USDA鸡油作旁证，但同样未在本轮作为原始查询页面验证，不用它替代原表定位结论。
3. 可用的官方公开替代数据是[豆油条目1497](https://nlc.chinanutri.cn/fq/foodinfo/1497.html)：3696kJ、F99.9g/100g。注意这与候选某些段落所写豆油3761kJ/899kcal不一致；不要混用。若按3g豆油作为明确的通用食用油估算，其他采用候选来源说明中所列选定值（熟鸡肉110g、辣酱10g、姜蓉10g、黄瓜25g）计算：
   - 能量：`232.1248 + 26.5014 + 240.9 + 12 + 47 + 3.5 = 562.0258 kcal`
   - 蛋白质：`5.122 + 27.148 + 0.2 + 0.1 + 0.175 = 32.745g`
   - 脂肪：`0.591 + 2.997 + 13.816 + 0.4 + 5 + 0.025 = 22.829g`
   - 碳水：`51.023 + 2.1 + 0.45 + 0.6 = 54.173g`
   - 合同取整为 **562 / 327 / 228 / 542**，与当前候选四项一致。该计算说明可以用有定位的油脂基准维持目前四项取整结果；它不证明3g是食堂实测量，也不证明食堂使用豆油。
4. 候选本身的 `nutritionBasis.source` 写“鸡油…或豆油替代”，没有唯一说明候选四项实际选用哪条数据。来源说明附有按鸡油897值和按替代值两套表述；旧值与替代值因3g用量而取整一致。建议明确本版本采用的唯一数据项、链接和能量换算，删除无页证的精炼禽脂原表断言，保留油量为工艺假设。
5. 姜葱蓉、黄瓜来源证据中并列了“主值/alt值”；候选来源说明的最终计算采用P1/C4.5、黄瓜E14/P0.7/F0.1/C2.4这一组，重算可复现。报告中的其他汇总段落若展示了替代值，应标出未用于JSON，避免读者误把两套数据混成最终取值。3g油、鸡肉110g、蘸料各10g、黄瓜25g均非后厨称重事实。
