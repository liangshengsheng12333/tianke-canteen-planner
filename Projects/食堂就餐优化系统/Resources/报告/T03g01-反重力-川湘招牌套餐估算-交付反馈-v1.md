   - 全部能量均为整数千卡（`energyKcal`）；

   - 无任何非法字段或二次截断。
2. **情景范围严格单调性（PASS）**：
   - 经自动化校验脚本遍历：全部 29 款套餐严格满足 `low.energyKcal < central.energyKcal < high.energyKcal`；
   - 宏量指标严格满足 `low <= central <= high`；
   - 情景变化来自真实物理打勺克重浮动（主菜 ±15%、两素 60g~80g、米饭 180g~220g）与用油增减，杜绝无依据的纯数学比例浮动。
3. **Atwater 4/9/4 理论供能复核（PASS）**：
   - 29款套餐的原料累加能量与 4/9/4 理论供能差值均控制在 1.11 ~ 12.92 kcal 之间（相对偏差均 ≤ 1.9%）；
   - 差值原因清晰明确：主要由蔬菜不可吸收膳食纤维折算、特定肉类/坚果长链不饱和脂肪酸实际燃烧系数以及国标千焦千卡换算精度引起，完全合乎营养生理学规律。
4. **固定整套价与结构合规（PASS）**：
   - 25 款招牌套餐保持整套价（1100、1200、1300 分），`priceBasis: comboTotal`，未拆分为单品价；
   - 完整遵循 `kind: combo` 与组件结构，米饭仅计一次，供午餐与晚餐。
