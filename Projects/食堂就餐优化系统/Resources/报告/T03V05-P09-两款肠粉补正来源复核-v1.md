## 逐项核对

### 共用熟肠粉基准

香港食物安全中心（CFS）官方 FRL 原始工作簿 `Nutrient_profiles_FRL.xlsx` 英文表第313行对应 `Steamed plain rice-roll (2021)`，即查询索引 Item 2395。原表每100g：能量100 kcal，蛋白质0.86g，可利用碳水23.0g，脂肪1.1g，膳食纤维Trace，钠66mg。200g熟粉皮相应为200 kcal、P1.72g、F2.20g、C46.00g、Na132mg。该数据支持作为两款的熟粉皮估算基线；它不证明食堂实际粉皮克重或现场额外用油。

CFS 的 `Nutrient_details.xlsx` 说明其能量算法为 `4×蛋白质 + 4×可利用碳水 + 9×总脂肪 + 7×酒精`。将该行宏量代入为 `4×0.86 + 4×23 + 9×1.1 = 105.34 kcal/100g`，与 FRL 公布的100 kcal相差5.34 kcal/100g。原附件已将其写成公布能量与宏量的差异，并明确官方资料未解释成因；此前“纤维扣除”或“千焦整百取整”的推测已删除。计算沿用 FRL 公布能量，不机械改成宏量换算结果，处理合适。

### 甜豉油来源、单位及替代边界

本批来源改为李锦记英国官方商品页 `Sweet Soy Sauce 207ml`，页面明确营养标示以每100g为基准：能量889kJ（209kcal）、蛋白质5.3g、脂肪`<0.5g`、碳水47.0g、盐13.6g。15g质量份量按 `15/100=0.15` 乘算：采用页面直接标注的209 kcal计算为31.35 kcal；P0.795g、C7.05g；脂肪`<0.075g`。这修正了 T03V03 所指出的 per100ml 与按15g直接乘算不一致问题。

替代 SKU 边界有明确披露：官方页面是207ml包装，未证明与食堂采购的国内410ml瓶装相同。因此这组数据可支持“以该官方产品作代表的估算”，不能称作食堂实际所用酱汁的实测/原包装营养值。页面列出原料水、糖、盐、焦糖色、大豆（7%）、小麦粉等；由于标签脂肪为上限格式，现有页面不足以证明实际脂肪为0。

官方页面同时给出889kJ与209kcal，两者按物理换算并不一致（889/4.184≈212.48 kcal）。候选采用明确标注的209 kcal列进行 `energyKcal` 乘算；按该列可复现候选值。若改用kJ换算，15g酱汁能量将约为31.87 kcal，原味整份仍约231.87 kcal（显示232），瘦肉整份约274.77 kcal（显示275）。建议说明中锁定“按厂商公布的kcal列”作为估算基准，并记录这项标签内的能量差异；本报告按此当前选择复核。

本批自写来源 JSON 把盐写为13.4g/100g（并据此算钠），但当前官方商品页标示盐13.6g/100g。钠不属于本卡要求的四个营养输出字段，因此不改变本次 E/P/F/C 裁定；该来源摘录应更正，避免把盐值说成与官网一致。

### `dish-plain-changfen`｜原味肠粉

配方假设为熟肠粉皮200g + 甜豉油15g，约215g成品；两项克重均非食堂实称。按CFS基准及厂家公布的每100g产品营养值：

- E：`200 + 209×0.15 = 231.35 kcal` → 231 kcal
- P：`0.86×2 + 5.3×0.15 = 2.515g` → 25dg（2.5g）
- F：`1.1×2 + [0, 0.075) = [2.200, 2.275)g`。按0.1g舍入，区间内可能为22dg或23dg。
- C：`23×2 + 47×0.15 = 53.050g` → 531dg（53.1g）

JSON的231/25/22/531在其选定kcal列及脂肪取下界时可复现。需修正文案：`<0.5g`标签只给出上限，不能据此认定实际脂肪趋近0或称22dg是唯一可推得的中心值；大豆作为原料也使“没有添加油脂”不等同于“原料脂肪为0”。可保留22dg为明确的下界估值，但应同步写明该项完整舍入范围为22–23dg；如要选中心点估值，则须把中心假设明确称为建模选择，而非标签事实。

### `dish-lean-pork-changfen`｜瘦肉肠粉（猪瘦肉）

配方假设为熟肠粉皮200g + 生猪瘦肉碎30g + 甜豉油15g，约245g成品；三项克重均非食堂实称。猪肉使用生鲜食物成分数据直接乘生投料量，没有再按熟重折算，避免重复缩放。中国疾控营养与健康所官方“猪肉（瘦）”查询页每100g列600kJ、P20.3g、F6.2g、C1.5g；本地来源记录对应《中国食物成分表》第六版第二册代码081110、第122页。600kJ换算143.4 kcal，书列143 kcal；30g差异仅0.12 kcal，整份整数能量显示不变。

按书列143 kcal和官网公布209 kcal列复算：

- E：`200 + 31.35 + 143×0.30 = 274.25 kcal` → 274 kcal
- P：`1.72 + 0.795 + 20.3×0.30 = 8.605g` → 86dg（8.6g）
- F：`2.20 + [0, 0.075) + 6.2×0.30 = [4.060, 4.135)g` → 整个区间均舍入为41dg（4.1g）
- C：`46 + 7.05 + 1.5×0.30 = 53.500g` → 535dg（53.5g）

候选274/86/41/535均可复现。即使甜豉油脂肪在官方上限范围内变化，整份脂肪仍稳定舍入为4.1g，所以不需为该输出字段补新的品牌脂肪实测值。官方207ml SKU与国内实际采购产品并未证实相同，但候选已明确将其作为代表估算基准；典型克重也明确标成估算，符合本卡边界。
