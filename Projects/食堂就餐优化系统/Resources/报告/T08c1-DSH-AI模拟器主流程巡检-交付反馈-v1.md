## 4. 去重缺陷清单

### D-01（阻断）换菜单后失效锁定无法在 UI 内解除，窗口锁提示出现字面 `undefined`

- **复现**：T08a1 DEFECT-01。前置＝当日有计划 + 已有锁定（窗口锁 1 条、菜品锁 2 条）+ 通过真实 UI 把菜单换成西一；随后今日页出现「锁定项需要处理 3 项」。
- 实际：点「解除窗口锁定」→ toast `undefined没有任何窗口供应，无法锁定窗口`（**字面 undefined**，2/2 次一致），`windowLocks` 仍 1 条；点「解除菜品锁定」→ toast「该报价已不在菜单中，无法锁定」，`itemLocks` 仍 2 条。页面明示「解决前不会生成新的合法方案」，形成**UI 内不可恢复的死锁**（只能清库/改 store）。
- 证据：`23/24/25` 截图 + `S2-缺陷01-失效锁定与解除尝试.json`（含 `lockIssues` 原始数据、toast 文案、点击前后锁计数）。
- 根因线索：`pages/home/index.ts:263` 构造 `lockIssues` 时缺 `meal` 字段 → `home/index.wxml:237/243` 的 `data-meal` 为空 → `home/index.ts:713-722` 两个清除处理器直接 `toggleWindowLock(undefined)` / `toggleItemLock(undefined, offerId)` → `domain/store.ts:681` 的 `findIndex` 恒 -1，落到「加锁」分支并失败；窗口分支用 `mealLabel(undefined)` 拼串，故打印 `undefined`。
- 影响：任何换菜单后仍保留旧锁的用户，换菜单后无法继续用推荐；提示文案含内部 ID 与 `undefined`。附带观察 O-02。

### D-02（主要）点一次「换一份」后整餐菜品全部被自动锁定，第二次换菜只报错

- **复现**：T08a1 DEFECT-02，且影响面**比原反馈更广**——不是"单菜餐次"才发生：任何菜品数、任何餐次，换完一次即整餐锁死。
- 实际（A，模拟菜单 3 菜）：`itemLocks` `[] → 3`（rice-full / rice-half / 新换的 greens），三道菜全显示「已锁定」，二次点击 toast「没有可替换的菜品（锁定项不能直接换）」，2/2 次一致。
- 实际（Lead，西一菜单单菜）：白切鸡饭 ￥11.00 → 脆皮烤鸭饭 ￥13.00 后 `locked=true`、`itemLocks` 1 条；二次点击同一 toast。**原 T08a1「单菜品餐次换一份后锁死」由此确认成立**。

## 6. 未测项与限制

**工具限制（非 App 缺陷）**

- T-01：`wx.showActionSheet / showModal / showToast` 是原生浮层，模拟器截图只拍到背景压暗、页面 DOM 无 selector 可点 → 用 `automation_wx_api` mock 与临时包装 `wx.showToast` 取证，**逐处标注**，用后已还原。
- T-02：首页「确认吃了」按钮与其上「换一份」同 class 前缀、无唯一类名；`:nth-child`/`:not`/`text=` 等选择器在本工具不生效（实测回落到首个匹配），故该按钮**真实点击未测**，确认流程改经记录页覆盖。
- T-03：`scroll-view` 内的「锁定窗口」按钮 tap 命中不稳定（无 toast、状态不变），窗口锁前置改用 store 夹具（已标注）。
- T-04：`chooseIndex` 对候选截断为 6 项并有显式 toast（源码注释声明），西一晚餐实际 11 个同窗报价 → 属设计内限制，非缺陷。
- T-05：模拟器运行在 x64 开发机，**不是红米真机**；项目窗口重开不等于手机杀进程。

**未测场景（明确未操作，不用"看起来正常"代替）**

- 系统主题由深→浅的实时跟随（模拟器无法改系统主题）。

## 9. 结论

- 四段入口均在**微信开发者工具模拟器**上以真实点击进入并留证；其中段 2 换菜链路被 D-01/D-02 卡死（可绕行），其余段通过或部分通过。T08a1 两处已知问题**全部复现**，另发现 1 条与 D-01 同源的阻断性变体（窗口锁路径 + 字面 `undefined`）及 8 条一般问题/观察项（含 1 条证据缺口 O-08）。
- 本卡范围内的主流程在模拟器上**不通过**：D-01 为阻断（换菜单后推荐链路死锁），D-02 为主要（换菜交互锁死）。二者均为前端层缺陷，均已定位到冻结候选的具体文件:行号。
- 本结论**不是**红米真机结论，**不构成** T08 达标或 T09 总验收；真机、跨日/断网、导出恢复等仍由 T08a2/T08c2/T09 覆盖。
