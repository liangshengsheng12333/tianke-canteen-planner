## 官方来源与差异

1. [中国疾控中心营养与健康所食物营养成分查询平台：标准粉切面](https://nlc.chinanutri.cn/fq/foodinfo/265.html) 当前页面列每100g水分29.7g、能量1202kJ、蛋白质8.5g、脂肪1.6g、碳水59.5g。作者来源摘录声称同一“切面”是熟面基准：水分59.8g、160kcal、P4.5、F0.4、C34.6。两组不是同一个数值/状态，作者所谓官方在线编码一一对应也未给出可查页面；不能把生切面条目直接当已证实的熟碱水掸面。200g 熟面可以估，但需说明熟化出品率/水分假设与碱水、拌油关系。地方标准只可说明其适用对象和规范范围，不证明本食堂的单份实测配方。
2. 湖北省卫健委 [2026年修订公告](https://wjw.hubei.gov.cn/zfxxgk/zc/gkwj/ywh/202602/t20260203_5869357.shtml) 和[标准原文](https://wjw.hubei.gov.cn/zfxxgk/zc/gkwj/ywh/202602/P020260203606082994686.pdf) 表明当前《武汉热干面（方便型）》为 **DBS42/005-2026**，代替 2022 版；其范围是预包装方便型热干面。作者证据所引 DBS42/005-2021 已过时，且现行方便食品标准本身不等同于现场现制面条的工艺称重数据。武汉市市场监管局公布的 [DB4201/T 699-2024](https://scjgj.wuhan.gov.cn/jggg/tzgg/202407/P020240725540620671173.pdf) 是生产企业生产管理规范，也不能单独证成文中的 110g→200g、加油量或餐品宏量营养估算。
3. [鸡蛋官方页](https://nlc.chinanutri.cn/fq/foodinfo/978.html) 支持 599kJ、P13.3/F8.8/C2.8 每100g，可用于鸡蛋汤中心估计。作者的来源文档没有给每个食物的直达链接，写门户首页与书目摘录不足以让我确认其余条目均对应所述食物状态。芝麻酱/香油、特一粉、糯米折熟饭、猪油、紫菜、虾皮、淀粉、酱油应继续逐项与官方可定位条目核对，尤其应区分干料、湿皮、生肉、熟制品。
4. 当前湖北官方公告也说明 2026 版刚更新；来源记录日期 2026-10-22 时应使用现行有效版，并清楚区分“武汉热干面（方便型）”与窗口现制热干面。报告没有把检索到的标准工艺参数外推为食堂已实测克数。
5. c2 证据 02 把三全馄饨皮、蔡林记挂面/调料包、安井烧麦和甜咸萝卜丁的数值写作“实物标签”，但未附标签图、厂商可定位商品页或条码核验结果（只有安井条码号文本）。因此这些营养值在本次核验中仍是作者二手摘录；它们不能作为已验证原始标签。李锦记/其他品牌首页式链接不构成单品凭证。标签数值、可食部或厂牌不符都需改为可复核原件，或明确改用可核通用成分表。

## 计算、单位和状态复核

- 六款 JSON 的 `energyKcal` 为整数 kcal，`proteinDg/fatDg/carbDg` 为 0.1g 单位；作者的乘积加总大多能按作者自列参数复算到 JSON 整数，份量相加也分别约为 259g、335g、464g、180g、300g。值标为 `estimated:true`；这些是菜品中心假设，不是出餐实测。
- 热干面计算约为 E 506.13 kcal、P 13.696g、F 16.323g、C 75.581g；换算取整为 506/137/163/756，与 JSON 匹配。但面条基准来源状态错误/未证实，不能因此接收。
- 小馄饨小份文内营养累加 E 263.06 kcal、P 11.596g、F 13.1315g、C 25.0991g；大份 E 416.265 kcal、P 18.5109g、F 20.5095g、C 40.1737g；按分克取整和 JSON 一致。两份 `nutritionBasis` 的面皮参考仍需核对产品原件。
- 猪肉复合比例计算存在具体偏差：作者列瘦肉 P20.3/F6.2/C1.5、肥肉 P2.4/F88.6/C2.5，80/20 加权应为 **P16.72、F22.68、C1.70 g/100g**，说明与计算分别用了 16.71/22.71/1.71。对小份 45g 馅影响约 P -0.005/F +0.027/C +0.005g；大份 72g 馅影响约 P -0.007/F +0.043/C +0.007g。虽不足以显著改变整数 dg，仍须更正数据链，不可声称复合计算严格精确。
- 烧麦说明的猪肉丁来源是“半肥瘦猪肉”395 kcal，宏量13.2/37/2.4；按24g纳入后，该来源与作者表内 JSON 数值可复算，但能量/宏量来源未绑定实际烧麦配方。工业烧麦标签“432 kcal/180g”与自估435 kcal相近，只是两个不同配方假设数值接近，不构成该窗口出品的交叉验证。
- 鸡蛋汤文内计算 E108.390、P6.690、F6.9025、C4.9450；分克为67/69/49，kcal为108，JSON 取整复现。这里 `49.45 dg` 四舍五入为49没有错。是否食堂实际用一蛋/香油/淀粉及份量仍仅为假设。
- 4/9/4 与来源能量差不要求被抹平；当前没有必要把差值解释为芝麻油“燃烧热”或其他特定机制，除非能以来源方法证成。
