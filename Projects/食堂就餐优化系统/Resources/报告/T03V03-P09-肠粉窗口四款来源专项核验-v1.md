## 2. 共用来源与计算核验

### 净肠粉与能量差异

本地 CFS 原始工作簿 `Nutrient_profiles_FRL.xlsx` 的 Eng 表第 313 行对应 `Steamed plain rice-roll (2021)`：每 100g 可食部分能量 100 kcal、蛋白质 0.86g、可利用碳水 23g、脂肪 1.1g、钠 66mg。CFS 官方营养查询索引也列有 Item 2395。按 `Nutrient_details.xlsx` 的说明，能量计算式为 4×蛋白质 + 4×可利用碳水 + 9×脂肪；同表说明可利用碳水以差减法计算。该宏量值折算为 105.34 kcal/100g，与 FRL 所列能量 100 kcal 有约 5.34 kcal 差异。

官方说明文件没有给出该条差异的具体成因。因此，草案把差额归因于“扣除不可利用纤维”或称为“千焦取整”均缺少该原始记录支持，应删除这段归因；估算可直接沿用 CFS 已发布的能量 100 kcal，宏量能量不必机械改成与 4/9/4 相等。CFS 数值支持估算基线，但不证明肠粉中脂肪具体来自蒸盘防粘油。可说 200g 基线已包含该检测样品的总脂肪 2.2g；不能把脂肪来源断言为防粘油，也不能在没有出餐观察证据时把“未另加油”说成现场事实。

### 甜豉油单位与计算

来源 JSON `04_李锦记港式甜豉油_GB28050法定营养标签.json` 把营养标示单位写为每 100ml，并给出密度约 1.15g/ml；但估算说明以“15g”作为份量，实际计算却直接乘以 15/100。这相当于把每 100ml 的数值按每 100g 使用。若坚持每 100ml 基准，15g 应先按密度换为约 13.04ml，再参与计算。

另查到李锦记官方欧洲产品页列出该品牌 Sweet Soy Sauce 每 100g：889kJ/209kcal、蛋白质 5.3g、脂肪 <0.5g、碳水 47g；其公开包装规格为 207ml，不能证明与本批 JSON 所称的国内 410ml SKU 完全相同。若以此官方每 100g 数据作为估算来源，15g 的营养贡献约为 31.35 kcal、P 0.795g、C 7.05g，脂肪小于 0.075g；现有计算数值基本就是按此每 100g 基准计算。最小补正是统一证据与计算口径：将依据改为该官方每100g产品资料并注明 SKU 对应关系尚未证实，或补入本批确切 410ml 产品的标签原件；如继续采用每100ml口径，则按 15g→13.04ml 重算。

### 份量、熟生重、用油与取整

照片能核实标牌菜名、价格与早餐档口属性，不能核实粉皮克重、肉肠规格、猪肉投料量、甜豉油量、豆浆杯量或配方。200g 熟肠粉皮、30g 生猪肉、30g 鸡肉肠、15g 酱汁及300g豆浆属于作者典型份量假设；只要保留 `estimated: true` 并明确不是实称，作为中心估算假设可接受。猪肉使用生重营养数据时，应乘生投料重；无需再以熟重缩放同一营养量。没有把鸡肉肠或猪肉重复当作主食/米饭计入。四款计算均未重复添加蒸盘油；这一点是估算边界，不是照片证实的现场工艺。

字段约定中 P/F/C 为分克，按 g×10 后取整；以下复算按候选实际选择的 15g 甜豉油、且采用制造商页面每100g数据进行，说明单位统一后现值大体成立：

- 原味：E = 200 + 31.35 = 231.35 kcal；P = 1.72 + 0.795 = 2.515g；F = 2.2 + <0.075g；C = 46 + 7.05 = 53.05g。显示值为 231 kcal、25dg、约22–23dg、531dg（脂肪需遵从明确的标签值或说明估算精度）。
- 鸡肉肠：原味基底 + 30g 肠；如果其标签 JSON 数值属实，则 E≈285.56 kcal、P≈5.815g、F≈5.5g、C≈55.90g，显示约286 kcal、58dg、55dg、559dg。算术可复现，但核心鸡肉肠营养来源尚未证实。
- 瘦肉：原味基底 + 30g 生瘦肉（采用估算说明的 143 kcal、P20.3/F6.2/C1.5 每100g）；E≈274.25 kcal、P≈8.605g、F≈4.06至<4.135g、C≈53.50g，显示约274 kcal、86dg、约41dg、535dg。使用来源中的 600kJ 而非 143kcal 时，能量差仅约0.1 kcal，显示不变。

## 3. 逐款裁定

### `dish-plain-changfen`｜原味肠粉

**裁定：需小补正。**

- 支持依据：CFS FRL 原始表第313行（Item 2395）是熟制净肠粉数据，能支持其作为 200g 熟粉皮估算基线；照片7和 T03b 菜单身份相符，标牌为早餐原味肠粉，价格6元。基础能量/宏量/钠单位可由原始表复核。
- 现值判断：能量与 P/F/C 现值按甜豉油每100g数据计算基本可复现；但本地来源附件称 per100ml，计算按15g直接乘比例，单位不一致，且来源称脂肪为0与官方页“<0.5g/100g”精度表达不一致。另有未经证实的能量差因解释和“粉皮脂肪即防粘油膜”的来源解释。
- 最小必修项：在来源附件和说明中统一甜豉油单位/产品规格与计算基准；修正或限定甜豉油脂肪字段；删除 CFS 能量差额的无来源归因；把“检测样品总脂肪”与“油脂来源”分开表述。200g熟粉皮和15g酱汁继续标作假设即可。
- 餐次：照片明确为早餐。该项当前需补正，尚不计入“可直接接收”的餐次覆盖。

### `dish-ham-changfen`｜火腿肠粉（鸡肉）

**裁定：缺关键来源不接收。**

- 支持依据：CFS 净肠粉基线同上；照片确认该早餐菜名为“火腿肠粉（鸡肉）”、7元。JSON 中假设一支30g鸡肉肠可作为透明的份量假设。
- 阻塞点：`03_双汇纯鸡肉肠_GB28050法定营养标签.json` 仅为本地自述标签转录；未附可辨认的原包装营养标签照片、厂商对应 SKU 页面或可核商品条码。名称在“纯鸡肉肠/鸡肉火腿肠”间摇摆，且30g规格无原件支持。仅有数值与能量复算不能证明数值属于所用产品。
- 最小必修项：补入可定位到准确双汇产品和规格的厂商单品页或包装正反面标签原件（含营养表/净含量/条码），据此复核每100g营养值及30g单支假设；并统一甜豉油单位问题。来源补齐前不接收。
- 餐次：照片明确为早餐；目前不计入可接收覆盖。

### `dish-lean-pork-changfen`｜瘦肉肠粉（猪瘦肉）

**裁定：需小补正。**

- 支持依据：照片确认早餐“瘦肉肠粉（猪瘦肉）”、8元。估算说明采用30g生猪瘦肉；中国营养科学数据平台的“猪肉（瘦）”条目可独立核对每100g食部100%、能量600kJ、P20.3g/F6.2g/C1.5g，与本批引用数值相合。生料按生重投料计算方法正确。
- 现值判断：在 15g 甜豉油按官方每100g制造商数据解释时，当前显示值可复现（能量约274.25kcal，P约8.605g，F约4.06g加酱汁微量，C约53.50g）；主要待改项来自甜豉油单位、精度，以及 CFS 共同基线的无来源能量/油脂来源解释。猪肉数据库 600kJ 与说明中 143kcal 的换算差异不足以改变 kcal 整数显示。
- 最小必修项：与原味肠粉相同，统一甜豉油营养值单位和SKU来源；改正 CFS 能量差和粉皮脂肪来源表述。保留“30g生瘦肉”为估算假设，不要称作食堂实称。
- 餐次：照片明确为早餐；该项需小补正后可覆盖早餐，与原味肠粉一起仍不构成已接收覆盖。

### `dish-grain-soymilk`｜五谷杂粮豆浆

**裁定：缺关键来源不接收。**

- 支持依据：照片确认早餐“五谷杂粮豆浆”、2元。CFS FRL 工作簿 Eng 表第172行（Item 2312）列普通甜豆浆每100g：41 kcal、P2.1g、C5.3g、F1.2g；中国食物成分表来源 JSON 另列熟甜豆浆 05-1-101 为 38 kcal、P2.2g、C5.0g、F1.2g。二者都是可参考的甜豆浆基线，但不能直接证明该食堂五谷杂粮配方。
- 阻塞点：草案称 38 kcal 等值为两来源“综合/中心值”，但两组数据的简单平均并非此值；也未提供五谷配料比例、豆水比例、糖量或验证方法。五谷杂粮对宏量/能量有实质影响，无法由普通甜豆浆的条目推导 300g 成品值。9–10盎司杯容量及300g净重也未由照片量出，但可作为明示假设，不是本项核心阻塞。
- 最小必修项：将其明确降格为“普通甜豆浆基准估算”，不再称五谷配方的计算结果；或补入实际配料比例/制作批次数据并解释选取哪一条每100g基准及换算方法。维持300g假设时须标明杯量未经实测。来源闭环前不接收。
- 餐次：照片明确为早餐；当前不计入可接收覆盖。
