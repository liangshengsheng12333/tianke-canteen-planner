## 核对依据与结果

### T03c11｜原味与瘦肉肠粉

本批草案含两项：原味肠粉231/25/22/531与瘦肉肠粉274/86/41/535（能量kcal，其余为dg）。输入路径为 `Resources/真实菜单/西院西一食堂-20261022/T03c11-v1/`。

**原味肠粉复算**：CFS FRL 官方工作簿 Eng 表第313行（Item 2395，Steamed plain rice-roll 2021）每100g为100kcal、P0.86g、F1.1g、可利用碳水23g；李锦记官方 Sweet Soy Sauce 207ml 页面每100g列209kcal、P5.3g、F<0.5g、C47g、盐13.6g。按熟粉皮200g、酱汁15g：

- E：`200 + 209×0.15 = 231.35 kcal` → 231
- P：`0.86×2 + 5.3×0.15 = 2.515g` → 25dg
- C：`23×2 + 47×0.15 = 53.050g` → 531dg
- F：`1.1×2 + [0,0.075) = [2.200,2.275)g`；按0.1g取整可能为22或23dg。

c11 JSON与说明已把22dg限定为“采用下界/选定点估的建模假设”，没有称为标签唯一推出的中心值，并完整保留22–23dg范围；这闭合了 T03V05 指出的必修项。由于配料含大豆，页面不能证明真实脂肪恰为零；报告将22dg视作透明估算点，不当作实测。官方产品规格207ml与食堂可能采购的国内410ml SKU未证实同款，候选继续披露该未知，故仅按代表性产品形成估算。

甜豉油盐值本批已更正为13.6g/100g（来源JSON折算钠5350.8mg/100g），闭合 T03V05 指出的13.4g摘录错误。官网同时公布889kJ与209kcal，889/4.184约为212.48kcal；候选已明确选取直接公布的209kcal列计算。CFS公布100kcal与其宏量按4/9/4折算105.34kcal的差异也已按公布值保留，没有继续猜测原因。

**瘦肉肠粉复核**：在共同基底上加生猪瘦肉30g。中国疾控营养与健康所官方“猪肉（瘦）”条目每100g为600kJ、P20.3g、F6.2g、C1.5g；本地证据记为第六版第二册代码081110。按书列143kcal计30g：E42.90、P6.09g、F1.86g、C0.45g。整份为E274.25kcal、P8.605g、F`[4.060,4.135)g`、C53.500g，取整为274/86/41/535，与 T03V05 接收值一致。酱汁脂肪的不确定区间不会改变整份41dg结果；生肉采用生重直接乘算，没有再按熟重缩放。

### T03c12｜白切鸡饭

只核 T03c12-v1 中 `dish-cpky-baiqieji-fan`，当前值493/332/148/542。官方蒸米饭条目287（编码01-2-401）为493kJ/100g，按4.184换算为117.8298kcal/100g；200g贡献235.6596kcal、P5.2g、F0.6g、C51.8g。候选另外采用熟带皮鸡肉110g、CFS烧味汁15g、白灼菜心35g的既有来源和透明份量假设：

- E：`235.6596 + 240.9 + 9.45 + 7 = 493.0096 kcal` → 493
- P：`5.2 + 27.148 + 0.255 + 0.63 = 33.233g` → 332dg
- F：`0.6 + 13.816 + 0.045 + 0.3185 = 14.7795g` → 148dg
- C：`51.8 + 0 + 1.95 + 0.42 = 54.17g` → 542dg

数值与候选一致。候选不再把493kJ写作116kcal，且JSON只保留契约字段`carbDg`。照片和米饭规格牌支持“有200g小份”这一现场事实，不证明该盘实际称重200g；鸡肉、酱汁、菜心克重仍属估算。本次状态仅接收有依据估算，不等于正式菜单批准。

### T03c16｜泰式豆腐饭

候选单菜JSON为633/274/265/716。493kJ米饭来源、油豆腐条目343（1018kJ、P17/F17.6/C4.9每100g）、熟油与黄瓜值按作者列示口径，条件性加总可重现约633.125kcal、P27.362g、F26.482g、C71.623g。若酱汁数据确为220kcal、P0/F0/C55每100g，25g对应55kcal、P0/F0/C13.75g，四项整数/分克结果可重现。

但本批 `04_李锦记泰式甜辣酱_法定标签与单品定位凭证.json` 是作者撰写的证据摘录，并非厂家原始标签。其声称国内 GB 28050 每100g为920kJ/220kcal、P0/F0/C55，并声称175g包装标签按每10g标示；证据目录无该标签照片或可辨认的包装背标。引用的李锦记香港175g官网商品页确实列22kcal、P0/F0/C5.5、糖4.8g、钠115mg，但网页未标“每份”或“每10g”口径；李锦记中国官网产品页列产品与配料、规格380g，没有营养表。官网数值与作者所称每10g恰好吻合，或4/9/4算术闭合，都不能替代营养表的原始单位证据。尝试打开官网商品图时，图像资源返回缓存未命中，未能以该图确认包装标签。

因此，25g折算前置条件未满足。最小补件为准确SKU的清晰原包装营养表照片（能看见计量基准与条码/规格），或厂家明确写出该SKU每100g数值的官方单品资料；随后再按实际单位确认25g贡献。来源补齐前应将该菜整份营养标为未知，不接受当前633/274/265/716。价格、餐次和份量假设不属于此项来源阻塞，也不在本报告中修改。
