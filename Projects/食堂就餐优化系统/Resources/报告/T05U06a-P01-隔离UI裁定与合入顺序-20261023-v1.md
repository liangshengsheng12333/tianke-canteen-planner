# T05U06a｜P01 隔离 UI 裁定与合入顺序（2026-10-23）

## 裁定

**接收为下一轮记录页 UI 候选，不在 T07b 正式计时期间合入生产。** P02 的阶段查收证明交付边界和材料身份；P01另看了空日浅色、已记浅色、已记深色及月历展开四张模拟器截图。重复 hero 已去掉，日期、当天记录和操作先于月度汇总；深浅色均可读，方向符合“首屏更轻、先看这一天”的设计目标。此结论不等于用户最终视觉满意或 T05U06b、真机、完整回归通过。

## 视觉核对

- 空日首屏能直接看到“记一餐”；已记首屏能看到当天早餐、食物和实付，月度汇总不再挡在前面。
- 月历收起/展开、深浅色的层级一致；展开月历后餐卡自然下移，符合展开行为。
- 仍有两处值得在合入时做定向小修：390px 模拟器里“营养（已知小计）”与数值挤到多行；空日同时出现总入口“记一餐”和各未记餐卡的“补记食物/结束餐次”，操作重复、首屏仍偏长。只调整这两处及必要文案，不扩大到页面重构。

## 顺序和边界

1. **现在可派**反重力 Gemini 3.8 执行 `Resources/任务提示词/T07b-反重力-固定候选性能与工程验证-v3.md`；实际是否已由用户手动转交、是否开工，当前未知。输入准备可与轻量文档/UI 方案并行，正式计时不与其他高负载任务并行。
2. T07b 正式计时和候选身份核对结束后，P01 再以 **DSH DeepSeek V4.1 Flash 小卡**安排 T05U06a 的两文件合入与上述两处小修。基线为当前正式候选，隔离版只作补丁来源；若 T07b 后正式候选已变化，先对比两个目标文件再合入，不整树覆盖。
3. 合入后只做记录页受影响检查和浅/深色预览；撤销实际点击、补记表单实际提交、系统跟随主题及红米真机留在 T08 统一候选验证。然后才评估 T05U06b 或更广 UI 收口。
