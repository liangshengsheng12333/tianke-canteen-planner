## 三、 P09 复核缺陷定点闭环整改要点

对照 `T03V07-P09-剩余三款营养修正定向复核-v1.md` 与本任务卡要求，逐条落实唯一定点整改：

### 3.1 彻底消除双基准与未定位断言，唯一定点于官方豆油条目 1497
- **原缺陷（P09指出）**：
  1. 鸡油 897 kcal、99.7g 脂肪的《成分表》记载没有具体书页与条目定位，当前证据只是转述；
  2. 候选与说明中出现“鸡油或豆油”双基准混写，且历史说明中曾误链 1041 页面（绿鳍马面豚）。
- **定点决策与闭环**：
  1. **废除未定位条目与错误链接**：彻底删除未定位的精炼禽脂原表断言，剔除 1041 错误链接；
  2. **唯一定点于官方豆油条目 1497**：
     - 权威直达页面：[官方中国疾控中心食物成分查询平台条目 1497（豆油）](https://nlc.chinanutri.cn/fq/foodinfo/1497.html)
     - 官方标定值：每 100g 能量 **3696 kJ**、脂肪 **99.9g**、蛋白质 **0.0g**、碳水化合物 **0.0g**、钠 **0.0mg**；
     - 国家标准能量折算（$1\text{ kcal} = 4.184\text{ kJ}$）：
       $$3696 \div 4.184 = \mathbf{883.3652\dots\text{ kcal/100g}}$$
  3. **3g 单份通用食用油工艺替代基准精算**：
     $$E = 0.03 \times 883.36520076 = \mathbf{26.5010\text{ kcal}}$$
     $$P = \mathbf{0.0000\text{ g}}$$
     $$F = 0.03 \times 99.90 = \mathbf{2.9970\text{ g}}$$
     $$C = \mathbf{0.0000\text{ g}}$$
  4. **工艺假设透明披露**：
     - 依据档口招牌“米饭鸡汤蒸 没菜也吃撑”（照片 2），熟米饭加入 3g 食用烹调油（与 197g 蒸白米饭合为标准小份 200g 熟重），赋予米饭金黄光泽与香气；
     - 明确声明这是配方工艺假设，绝不代表后厨实际称重，亦不冒称后厨实际使用大豆油或纯鸡油。

### 3.2 明确姜葱蓉与黄瓜唯一采用组，杜绝与 alt 值混淆
- **姜葱蓉调料（10g）**：明确采用 CFS FRL Row 86 组分（能量 470 kcal、蛋白质 1.0g、脂肪 50.0g、碳水 4.5g / 100g），10g 贡献 **47.0000 kcal**、蛋白质 **0.1000g**、脂肪 **5.0000g**、碳水 **0.4500g**。绝不混写备选值（1.7g / 5.2g）；
