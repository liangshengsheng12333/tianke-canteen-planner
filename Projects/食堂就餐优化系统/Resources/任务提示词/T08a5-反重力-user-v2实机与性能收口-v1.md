每次调用保留完整请求和响应、profile/targets、餐次、预算、锁定/售罄条件、算法、实际参数、结果状态、截断标志、时间和失败原因。保存逐次原始样本及 median/min/max；超时和失败也计入并保留。所有组的真实请求/响应应能证明输入一致且不含真实个人资料。正式测量时 Redmi 不与同设备重负载并行；单次高成本核心调用外部硬超时 25 秒，超时即保存失败记录，不无限重跑。

分开报告以下指标和观测方法：

1. **WASM 核心 `mp_plan`**：完整调用起止，含解析、搜索和输出，排除模块首次加载及页面绘制；目标 G1—G3 各组正式中位数 `≤50 ms`。

3. **WASM 线性内存**：同一实际 WASM 实例连续调用期间，记录 `memory.buffer.byteLength / 65536` 完整采样序列、各组最高页数、分配失败；目标 `≤768 pages`（48 MiB）。RSS、Node、模拟器或手机总内存都不能替代此指标。
4. **桥接及启动体验**：UTF-8 编码、输入/结果复制、显式释放、桥接往返、模块冷加载、冷启动到可交互、首次方案分别记录，不混入核心-only 耗时。
