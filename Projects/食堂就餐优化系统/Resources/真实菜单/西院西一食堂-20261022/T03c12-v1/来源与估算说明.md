## 一、 P09 复核意见整改闭环与米饭基准修正

依据 `T03V04-P09-六款补正营养来源复核-v1.md` 第一节对白切鸡饭的复核意见，本次 T03c12 定点小修完成以下整改闭环：

### 1.1 米饭能量单位冲突彻底消除
- **历史缺陷（T03c5-v1）**：说明及 JSON 中同时出现“493 kJ/100g”与“116 kcal/100g”。但按国际/国家标准能量换算常数（1 kcal = 4.184 kJ），`493 ÷ 4.184 = 117.8298 kcal/100g`（约 117.83 kcal/100g），两者存在单位换算冲突。
- **本次修正落实**：
  * 数据源唯一定位为中国疾病预防控制中心营养与健康所食物成分查询平台官方条目：**“米饭(蒸)”（编码 01-2-401，条目 287）**；
  * 官方平台明确标定：能量 **493 kJ / 100g**、蛋白质 2.6g / 100g、脂肪 0.3g / 100g、碳水化合物 25.9g / 100g、钠 2.5mg / 100g；
  * 严格执行国标换算：`493 kJ ÷ 4.184 kJ/kcal = 117.8298 kcal/100g`（保留两位小数为 117.83 kcal/100g）；
  * 彻底废除 116 kcal/100g 的不一致写法，消除来源混写；
  * 200g 熟米饭基准能量由原 `116.0 × 2 = 232.00 kcal` 重算为：
    `2.0 × (493 ÷ 4.184) = 235.6596 kcal`（保留两位小数约 235.66 kcal），净增 **+3.6596 kcal**；
  * 蛋白质、脂肪、碳水化合物三项宏量不受能量单位换算影响，保持完全不变。

### 1.2 现场展板数据差异客观披露
- 现场立柱营养展板（照片 1，SHA-256 前 16 位 `4f764b8054352644`）第一行公示米饭数据为：486.00 kJ、蛋白质 2.60g、脂肪 0.30g、碳水化合物 25.90g；
- 换算能量为 `486 ÷ 4.184 = 116.16 kcal/100g`；
- 中国疾控中心官方平台标定为 493 kJ/100g（换算 117.83 kcal/100g）；
- 两者宏量完全一致，能量存在 7 kJ (1.67 kcal) 微小差异。本工程明确选用中国疾控中心国家官方平台可定位的 493 kJ/100g 标定值，并如实客观披露该现场差异，绝不掩盖或混淆。

### 1.3 契约字段格式规范修复
- **历史缺陷（T03c5-v1）**：JSON 中同时包含了 `nutrition.carbDg` 与 `nutrition.carbsDg`。根据系统契约定义，`carbsDg` 属于非契约冗余字段。
- **本次修正落实**：
  * 在新生成的 `营养估算草案.json` 中彻底删除 `nutrition.carbsDg`；
  * 仅保留合规契约字段 `nutrition.carbDg: 542`。
