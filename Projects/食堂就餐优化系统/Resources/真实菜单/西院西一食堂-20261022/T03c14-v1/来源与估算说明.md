## 一、 P09 专项复核整改闭环与事实界定

依据 `Resources/报告/T03V04-P09-六款补正营养来源复核-v1.md` 第 15、39~41、57 条及任务卡要求，本次定点小修完成以下整改闭环：

### 1.1 官方替代基准替换与声明边界
- **历史缺陷（P09 意见）**：
  前版草案（T03c8-v1）采用三全原味手抓饼 1440 kJ 标签，但三全单品 1440 kJ 标签未有原包装照片或厂家单品页可核，无法认作已独立核实的三全标签；P09 提出可改用官方预包装食品营养标签查询系统中的云鹤手抓饼条目作为清楚标注的代表替代项（1360 kJ、P 6.6 / F 14.1 / C 42.7 每 100g）。
- **整改落实**：
  1. **采纳国家官方标签库权威条目**：采纳中国疾病预防控制中心预包装食品营养标签查询系统收录的“云鹤手抓饼”条目（直链：`https://nlc.chinanutri.cn/food/03KqaiXHSPan6AjjRCOjWg.html`）作为明确的代表性替代基准；
  2. **严格明晰性质边界**：
     * **代表性替代基准**：云鹤手抓饼为国家级权威食品标签数据库收录的标准工业速冻手抓饼生坯条目；
     * **食堂档口实际品牌未知**：现场门头实拍与操作台并未展示或公示具体采购品牌，档口后厨实际采购品牌未知；
     * **严禁写成食堂实际采购品牌**：本说明及 JSON 草案明确披露云鹤仅为国家官方数据库代表替代品，绝不将云鹤写成食堂后厨实际品牌。

### 1.2 关键契约修复：彻底删除非契约字段 `nutrition.carbsDg`
- **历史缺陷（P09 意见）**：
  P09 报告第 57 条明确指出：c8 手抓饼 JSON 的 `nutrition.carbsDg` 与 `nutrition.carbDg` 同值，但 `carbsDg` 不属于当前契约字段；在正式入菜单前必须删除 `carbsDg` 并生成新的候选身份，不得原样合入。
- **整改落实**：
  本草案新生成的 `营养估算草案.json` 中，已彻底移除非契约字段 `nutrition.carbsDg`，仅保留契约规范字段 `nutrition.carbDg`。

### 1.3 用油用途物理归属彻底理清（杜绝双重计油）
- **物理工艺事实**：
  1. **手抓饼生坯自带起酥油**：云鹤手抓饼生坯脂肪占比 14.1%，单片 90g 自身已含有 **12.69g 丰富油脂**。热铁板加热时生坯油脂受热自溶出油，煎烙饼皮自身物理上无需额外倒油防粘，故不额外计入底油；
  2. **外加植物油物理用途拆解（共 3g）**：
     * **环节 A（土豆丝大锅预炒吸附油）**：约 **1.5g**。清炒根茎类蔬菜少油快炒吸油率约 3.3%，单份 45g 生土豆丝净料烹炒吸附约 1.5g 植物油；
     * **环节 B（铁板打蛋微量润锅防粘油）**：约 **1.5g**。档口师傅在铁板打蛋区域用油刷抹极薄一层油以防蛋清粘底焦糊；
     * **合计恰为 3g 烹调大豆油**。土豆丝直接按生马铃薯纯净原料核算，外加植物油统合归集于“烹调植物油 3g”单一条目，彻底消除重复计油。

### 1.4 整份逐项精算累加，不保留旧总值凑数
- **整改落实**：
  以云鹤手抓饼 90g 替代基准、鲜鸡蛋 50g、生马铃薯 45g、大豆油 3g 逐项乘积累加，求得未舍入总值：能量 **427.66 kcal**、蛋白质 **13.14 g**、脂肪 **20.277 g**、碳水化合物 **46.605 g**。

  - `carbDg` = **466** (46.6g)

## 五、 多轨供能核查与客观差值披露
