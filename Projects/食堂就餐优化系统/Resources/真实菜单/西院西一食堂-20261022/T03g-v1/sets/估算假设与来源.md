## 一、 执行原则与纪律核查

1. **严守用户新授权纪律**：2026-10-24 用户明确指令“我给不了你任何数据了，不是提供了图片吗，自己去估算”。本报告及估算数据**零次向用户追问**配方、重量、品牌或更多照片，完全基于已有照片外观特征与成熟工业餐饮典型标准推导。
2. **固定整套价原则**：
   - 门头标牌原文明确标注“11元”、“12元”、“13元”为“指定主菜 + 任选两素 + 米”的整套总价，原图无单独主菜或单独素菜单价；
   - 严禁将套餐价格拆解或克扣后冒充单主菜单价；套餐价格在报价体系中严格保持为整套价（1100、1200、1300 分，priceBasis: comboTotal）。
3. **主食米饭唯一计入与续饭口径**：
   - 依据西一食堂现场立柱统一出餐规格标牌（照片11），单份主食米饭区分为标准小份200g与大份400g；
   - 套餐内米饭统一按标准小份 200g 熟白米饭（约 117.83 kcal/100g）计算，单套仅计一次；
   - 档口虽有“免费加米”服务承诺，但按口径规范“不把无限当实际食量”，基准估算绝不假定顾客续了多少。
4. **两素配菜透明假设边界**：
   - 门头看板未公示可选素菜明细（符合现场缺少素菜价签之事实）；
   - 依据川湘小厨台面补拍实景（照片3与照片4等），中心情景选择台面出镜频次最高、最经典的**清炒西蓝花 70g** 与 **手撕包菜 70g** 作为透明代表搭配；
   - 明确保留免责声明：两素为典型工艺组合假设，非店员现场确认固定绑定。
5. **数据契约与情景范围**：
   - 生产字段严格遵循契约：`energyKcal`（整数）、`proteinDg`、`fatDg`、`carbDg`（分克，0.1g）；
   - 标记 `nutritionBasis.estimated = true`，`source = "照片与典型份量估算"`；
   - 每一道均给出由具体份量与油酱浮动驱动的 `low`（打勺偏紧/控油控酱）、`central`（标准出品）、`high`（打勺偏松/重油稠汁）情景范围，严格满足 `low < central < high`；
   - 披露 4/9/4 Atwater 理论供能及差值复核。
