## 一、 P09 定向复核意见与整改彻底闭环

在 P09 专项定向复核报告（`Resources/报告/T03V07-P09-剩余三款营养修正定向复核-v1.md`）第 14、29~36 条中，指出了 T03c14 存在的关键缺陷：
1. **在线直链与采用值混写**：T03c14 中鸡蛋、土豆、大豆油引用了官方在线查询页面链接，但实际采用的数据却来自未附原书页码的纸本表格，致使在线直链无法支撑填写值，来源闭环悬空。
2. **云鹤标签钠摘录笔误**：云鹤手抓饼官方标签页面钠标示为 **446 mg/100g**，T03c14 摘录中误写为 508 mg/100g。
3. **官方页面原值重算基准**：P09 按官方公开页面直查原值测算，全餐四项营养结果为 **426 kcal / 135 dg / 202 dg / 476 dg**，而原候选填写为 428 / 131 / 203 / 466。

针对上述缺陷，T03c18 采取如下整改落实：
- **彻底消除混写**：放弃缺乏公开可定位书页佐证的旧纸本数值，全面统一采用**中国疾控中心预包装食品营养标签查询系统**及**食物营养成分查询平台官方页面直查原值**；
- **纠正笔误**：云鹤标签钠标示修正为 446 mg/100g；
- **重算对齐**：按照公开可定位页面的原值，对 90g饼、50g蛋、45g土豆、3g油进行十进制高精度累加重算，最终四项契约取整完全对齐 P09 测算的 **426 kcal / 135 dg / 202 dg / 476 dg**，实现 100% 来源闭环。

## 三、 单份手抓饼物理工艺与用油归属拆解

手抓饼现场标准制作工艺拆解与用油归集如下：
1. **云鹤手抓饼生坯（90g）**：
   - 市售工业速冻生坯单片中心克重 90g（范围 85 ~ 95g）；
   - 生坯开酥工艺自带 14.1% 丰富起酥油（单片 90g 自身含脂 12.69g）；
   - 烙制时受热自溶出油，煎烙饼皮物理上完全不需要额外倒油防粘，**生坯不计额外底油**。
2. **鲜鸡蛋（全蛋去壳 50g）**：
   - 现场标准鲜鸡蛋 1 枚，去壳可食部净重中心值 50g（范围 45 ~ 55g）；
   - 在铁板打蛋区域磕开摊匀，与饼皮粘合烘熟。
3. **生马铃薯（土豆丝净料 45g）**：
   - 档口标准单勺夹心土豆丝，对应生马铃薯净料重按中心估计 45g 计（范围 35 ~ 55g）；
   - 土豆丝纯净原料按生马铃薯成分核算，炒制吸附油纳入外加油。
4. **外加烹调大豆油（3g）**：
   - **环节 A（土豆丝大锅预炒吸附油）**：约 1.5g（清炒根茎类蔬菜少油快炒吸油率约 3.3%，`45g * 3.3% = 1.485g ≈ 1.5g`）；
   - **环节 B（铁板打蛋微量润锅防粘油）**：约 1.5g（档口师傅在铁板打蛋处用油刷抹薄油以防粘底）；
   - **统合归集**：整份手抓饼额外消耗烹调油统归为 3g 大豆油，不与生坯自带油脂重叠。
5. **单份成品净重中心估计**：约 **185g**（波动范围 165 ~ 205g）。
