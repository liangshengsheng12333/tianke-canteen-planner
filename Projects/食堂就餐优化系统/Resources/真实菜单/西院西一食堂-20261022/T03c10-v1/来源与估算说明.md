## 一、 审查缺口闭环与修改原则说明

依据 P09 专项核验报告 `Resources/报告/T03V03-P09-肠粉窗口四款来源专项核验-v1.md` 与任务卡 `T03c10-反重力-原味与瘦肉肠粉共用来源小修-v1.md` 的指示，本小修版针对原 `T03c3-v2` 草案实施了以下四项彻底核正与规范化收口：

1. **统一甜豉油营养标示的产品规格、单位与计算口径**：
   - 草案原 JSON 标称每 100ml 并给出密度约 1.15g/ml，但在计算 15g 份量时却直接乘以 15/100，存在“混写 per 100ml 来源与 per 100g 乘法”的算术逻辑矛盾。
   - 本次正式统一采用具有公开可直接查验 URL 的李锦记官方欧洲单品 Sweet Soy Sauce 网页（per 100g 标示）作为权威依据；
   - **客观声明**：官方该包装规格为 207ml，其与草案原称之国内 410ml 市售 SKU 的对应关系尚未获得权威证实；但二者核心原料一致，且是目前唯一官方公开披露 per 100g 数据的基准；
   - 15g 份量严格按质量比 `15 / 100 = 0.15` 乘算，单位完全闭环。
2. **严谨处理甜豉油微量脂肪与数据契约精度**：
   - 官方单品标示脂肪为 `<0.5g / 100g`（微量脂肪法定上限标示），不伪装成精确的 0.00g 已知数；
   - 15g 酱汁对应的理论脂肪贡献区间为 `[0.000g, 0.075g)`；
   - 结合数据契约 `fatDg` 的分克（0.1g）取整规则，原味肠粉取中心值 22 dg（理论上限 23 dg），瘦肉肠粉在整个不确定性区间内取整恒为 41 dg，给出完全透明的精度分析。
3. **纠正 CFS 净肠粉官方数据与 4/9/4 差异的成因表述**：
   - CFS 净肠粉官方原表（Item 2395）公布能量为 100 kcal/100g，而按 4/9/4 宏量折算为 105.34 kcal/100g，固有差异为 5.34 kcal/100g；
   - 官方原始文献未对该差额给出成因解释，本估算**坚决删除**草案中关于“扣除膳食纤维”或“千焦整百取整”的无来源推测，如实保留为官方实测与公布数据固有差异；
   - CFS 官方化验样品实测总脂肪为 1.1g/100g（单份 200g 基线含 2.2g 脂肪），如实保留为基线数据，**不武断断言**这 2.2g 脂肪全部来自蒸盘防粘油，亦不断言现场师傅未额外刷油，仅作为未观测到额外加油时的中心基准。
4. **透明化中心份量假设，杜绝冒称现场实测**：
   - 熟粉皮 200g、生猪瘦肉碎 30g、调味甜豉油 15g 均明确标为“中心份量假设”，严格保留 `estimated: true`；
   - 猪瘦肉核对中国食物成分表第6版第二册标准编码 081110，生重投料 30g 乘生重营养数据，不经熟重重复缩放，kJ↔kcal 与 g↔dg 取整完全校验。

## 三、 两款餐品逐步推导、换算过程与独立复算

依据系统契约：
- `energyKcal` 为整数千卡（kcal）；
- `proteinDg`、`fatDg`、`carbDg` 为整数分克（0.1g，即 dg = `round_half_up(g * 10)`）；
- 保留 `estimated: true`。

### 1. 原味肠粉（`dish-plain-changfen`）

- **标牌菜名与价格**：`原味肠粉`，6元（600分），早餐（breakfast）。
- **中心份量假设**：
  * 现蒸熟净粉皮：**200g**（典型 2 条卷折份量，非食堂实称，合理波动 180 ~ 220g）
  * 调味甜豉油汁：**15g**（典型单勺淋汁份量，非食堂实称，合理波动 12 ~ 20g）
  * **单份成品净重中心估计**：约 **215g**
- **逐项原料物理与营养乘积计算**：
  * **熟净粉皮（200g，乘数 2.0）**：
    - 能量：`100 * 2.0 = 200.00 kcal`
    - 蛋白质：`0.86 * 2.0 = 1.720 g`
    - 脂肪：`1.10 * 2.0 = 2.200 g`（化验样品总脂肪，未断言防粘油归属）
    - 碳水化合物：`23.00 * 2.0 = 46.000 g`
    - 钠：`66.0 * 2.0 = 132.0 mg`
  * **调味甜豉油汁（15g，乘数 15/100 = 0.15）**：
    - 能量：`209 * 0.15 = 31.35 kcal`
    - 蛋白质：`5.3 * 0.15 = 0.795 g`
    - 脂肪：`<0.5g * 0.15 = <0.075 g`（理论区间 `[0.000g, 0.075g)`，无添加外来油脂）
    - 碳水化合物：`47.0 * 0.15 = 7.050 g`
    - 钠：按盐 13.4g 折算约 `5275.6 * 0.15 = 791.3 mg`（或按原标示 5350 约 802.5 mg）
- **合计与契约取整**：
  * **能量（energyKcal）**：
    `200.00 + 31.35 = 231.35 kcal` → 四舍五入取整为 **231 kcal**
  * **蛋白质（proteinDg）**：
    `1.720 + 0.795 = 2.515 g` → `round_half_up(2.515 * 10) = round_half_up(25.15) =` **25 dg** (2.5g)
  * **脂肪（fatDg）**：
    - 理论下限（豉油脂肪按 0.000g 计）：`2.200 + 0.000 = 2.200 g` → `round_half_up(22.0) =` **22 dg** (2.2g)
    - 理论上限（豉油脂肪按 0.075g 极值计）：`2.200 + 0.075 = 2.275 g` → `round_half_up(22.75) =` **23 dg** (2.3g)
    - **中心决策**：豉油配基为酿造酱油、水、糖，不含动植物油脂，微量大豆脂肪实际趋近于 0，中心估计取 **22 dg**，同时在契约与说明中披露上限为 23 dg。
  * **碳水化合物（carbDg）**：
    `46.000 + 7.050 = 53.050 g` → `round_half_up(53.050 * 10) = round_half_up(530.50) =` **531 dg** (53.1g)
- **Atwater 4/9/4 宏量复算对比与固有差异说明**：
  * 宏量复算能量：`2.515 * 4 + 2.200 * 9 + 53.050 * 4 = 10.06 + 19.80 + 212.20 = 242.06 kcal`
  * 差值：`242.06 - 231.35 = +10.71 kcal`
  * **科学说明**：该差值由 CFS 净肠粉官方数据固有偏差（单份 200g 粉皮产生 `2 * 5.34 = 10.68 kcal` 差额）及豉油微小舍入构成。如实保留官方实测公布值，不强行机械配平。

## 五、 敏感性分析：每100g质量法 vs 每100ml密度体积法

若未来取得食堂确切使用之国内 410ml 包装且法定标签证实为每 100ml 标示，按推测密度约 1.15 g/ml 计算：
- 15g 对应体积为 `15 / 1.15 = 13.04 ml`；
- 甜豉油 13.04 ml 贡献：能量 27.26 kcal，P 0.691g，F 0.0g，C 6.13g；
- 原味肠粉结果：能量 `200 + 27.26 = 227.26 kcal`（取整 **227 kcal**，差 4 kcal）；P **24 dg**（差 1 dg）；F **22 dg**（完全一致）；C **521 dg**（差 10 dg / 1.0g）；
- 瘦肉肠粉结果：能量 `227.26 + 42.90 = 270.16 kcal`（取整 **270 kcal**，差 4 kcal）；P **85 dg**（差 1 dg）；F **41 dg**（完全一致）；C **526 dg**（差 9 dg / 0.9g）。

**结论**：两套口径在能量上差异仅约 1.5%（4 kcal），宏量差异均 ≤ 1g。本小修版遵从 P09 明确指导，统一采用官方可公开查验的每 100g 标示作为基准，消除了“标称 per 100ml 却按 per 100g 乘算”的算术逻辑缺陷。
