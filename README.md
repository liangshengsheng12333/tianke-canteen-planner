## 📖 项目简介

**《天科食客》** 是一套面向高校校园食堂的智能就餐规划与营养优化引擎。项目旨在解决师生在食堂就餐时**“预算受限、营养失衡、窗口排队决策困难、菜品组合空间爆炸”**等实际痛点。

系统底层采用纯 **C++20** 构建高性能离散组合优化求解内核，通过 **WebAssembly (WASM)** 技术无缝编译并在微信小程序前端沙箱中单线程离线运行，实现**无需后端服务器参与、零网络延迟、毫秒级本地高精度就餐方案生成**。

## 🚀 核心算法矩阵

针对多目标就餐规划（预算约束、卡路里控制、蛋白质/脂肪/碳水三大营养素配比平衡、口味多样性与窗口分布），求解引擎研发并集成了三大规划算法：

| 算法类型 | 核心机理 | 求解耗时 | 空间占用 | 最优性保证 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **贪心启发式 (Greedy)** | 营养性价比梯度递推，快速截断 | **< 1 ms** | $O(N)$ 极小 | 局部近似最优 | 极速秒级推荐、网络极度受限或冷启动 |
| **动态规划 (DP 20K 网格化)** | 状态去重记忆化 + 能量离散网格桶 | **~71 ms** (原 23.46s 提速 **330.4x**) | $O(B \times C)$ 紧致 | 离散空间全局最优 | 追求营养素与预算精确平衡的主推荐 |
| **分支限界法 (BnB)** | 严格上界函数松弛评估 + 自由度(DoF)深度剪枝 | **~86 ms** | $O(\text{Tree Depth})$ 受控 | 连续松弛边界全局最优 | 多窗口复杂组合、极小残差约束下的极致寻优 |

### 💡 核心攻坚突破：DP 20K 提速 330 倍
在初始版本中，多营养素连续状态组合导致搜索空间发生指数级爆炸，PC 端计算一度卡死达 **23.46 秒**。团队通过底层两大工程重构：
1. **记忆化去重（不算重复账）**：采用高效哈希缓存已访问状态转移路径；
2. **状态网格归拢（归拢小格子）**：建立 20K 能量网格桶，消除连续浮点噪声；
最终将求解耗时降至 **71 毫秒**，提速 **330.4 倍**，使高复杂度算法顺利在移动端沙箱毫秒级运行。

## 🛠️ 本地构建与快速上手

### 环境要求
- **C++ 编译器**：支持 C++20 的 MSVC (Visual Studio 2022+)、Clang 15+ 或 GCC 11+
- **构建环境**：PowerShell 7+ / 5.1
- **Node.js**：v18+ (用于前端构建与验证脚本)
- **微信开发者工具**：用于小程序本地预览

### 1. 编译并运行 C++ 原生 CLI
```powershell
cd "Projects\食堂就餐优化系统\tools\core"

# 编译原生 CLI 工具
.\build_native.ps1

# 执行单元测试与求解回归
node run_t04_regression.mjs
```

### 2. 编译 WebAssembly 模块
```powershell
cd "Projects\食堂就餐优化系统\tools\core"

# 构建 WASM 导出模块至 miniprogram/src/assets/
.\build_wasm.ps1
```

### 3. 运行微信小程序
1. 打开 **微信开发者工具**；
2. 选择 **导入项目**，项目根目录选择：`Projects/食堂就餐优化系统/miniprogram`；
3. 填入您的测试 AppID 或使用“测试号”；
4. 编译预览，即可在模拟器中体验毫秒级就餐智能规划。
